# 项目概览

TinyAgent 是 AI Agent 学习与实验仓库：以**从零手写 → 自研框架 → 框架实战与生态**为学习主线，沉淀一个教学级、可扩展的 Agent 框架，并以 Experiment Copilot（实验副驾驶）作为贯穿式载体应用。

- [architecture](architecture.md) — 双主线结构、当前与目标目录
- [learning-path](learning-path.md) — L0–L6 学习地图与 M0–M5 里程碑
- [repo-map](repo-map.md) — 代码 → 文档映射
- [terminology](terminology.md) — 术语约定
- [environment](environment.md) — 环境搭建与配置
