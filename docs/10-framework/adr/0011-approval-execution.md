# ADR-0011：个人 Agent 审批与执行安全

> 所属：[TinyAgent Docs](../../README.md) › [自研框架](../index.md) › ADR

日期：2026-10-30 ｜ 状态：P4 已实现记忆/Skills 与无人值守安全

## 背景

个人 Agent 会读写工作区、运行命令、保存长期记忆，并会无人值守执行。审批决定是否允许，执行后端决定实际能影响什么；提示词不能作为安全边界。

## 决策

### 1. 统一检查顺序

```text
工具与参数解析 → 硬拒绝规则 → 模式约束 → 风险分级 → 审批 → 执行后端
```

- 风险为 `SAFE / CONFIRM / DENY`；未登记工具默认 CONFIRM，硬拒绝优先于人工批准。
- plan 模式只允许只读调查与提交计划；子 Run 继承父模式，权限不得扩大。
- unattended 仅放行创建任务时明确预授权的操作，未授权和超时默认拒绝。
- 适合模型换路的拒绝原因作为工具结果回填；不可恢复的硬拒绝可终止 Run。

### 2. 工作区、记忆与 Skills

- 文件检查和执行共用 `resolve()` 后路径判断，覆盖绝对路径、`..` 和符号链接。
- SQLite、凭证、MCP 配置、Skills 源和 USER/MEMORY 位于 workspace 外或受保护路径。
- 按 D15，稳定记忆可在主会话自动写入，但必须记录审计、支持增删改和容量限制；定时任务与子 Run 不得自动写长期记忆。
- Skills 只能先写待审核目录，人工审核后进入正式只读目录；MCP 工具默认 CONFIRM，描述和结果均视为不可信输入。
- 会话或事件回滚不代表文件、命令和外部副作用已回滚。

### 3. 后端与降级

| 后端 | 策略 |
|---|---|
| macOS 工作区沙箱 | 评估 Seatbelt，限制写入工作区和显式临时目录 |
| Linux 工作区沙箱 | 评估 bubblewrap，挂载最小读写集合 |
| Windows | 可标记沙箱不可用，走降级策略 |
| Docker/SSH/云端 | 后续按 Hermes 式 ExecutionBackend 扩展，不作首期依赖 |

按 D11，沙箱不可用或启动失败时：只读可继续；写入与 shell 必须每次展示真实参数并人工确认后才可本地执行；不允许“本次会话一直允许”，无人值守直接拒绝，并明确提示没有硬隔离。

### 4. 命令、渠道与凭证

- shell 固定工作目录、超时和输出上限，白名单入口优先于任意 shell；黑名单只防明显误操作。
- 首发 CLI 复用本地用户身份；未来聊天渠道必须有用户白名单、私聊优先、确认超时拒绝和 Bot Token 保护。
- 凭证由程序配置或专用存储注入，不进入工具结果、事件明文字段或 Agent 可读写区域。

## 后果与验证

记忆自动化提高学习体验，技能审核与降级确认保持边界；确认后的本地执行仍没有硬隔离。测试覆盖未知工具、路径穿越、自动记忆审计、定时/子 Run 写记忆拒绝、技能未审核不可执行、沙箱降级、无人值守、渠道白名单和凭证泄漏。
