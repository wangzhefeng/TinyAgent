# ADR-0010：ContextView 与学习上下文

> 所属：[TinyAgent Docs](../../README.md) › [自研框架](../index.md) › ADR

日期：2026-10-30 ｜ 状态：P3 已实现 ContextView 与学习上下文

## 背景

个人 Agent 的上下文既包含当前对话，也包含记忆快照、Skills 目录和历史检索。参考 Pi 的原始历史/模型视图分离及 Hermes 的冻结记忆与压缩前记忆机会，避免所有信息常驻 prompt。

## 决策

### 1. ContextBuilder

每次模型调用前生成 `ContextView`，至少包含 `messages / source_seq / artifacts / estimated / usage`。原始事件不变，摘要记录来源范围并可重建。

常驻内容只包括最新系统约定、当前任务、最新计划、冻结的 USER/MEMORY 快照和 Skills 名称/简述。Skills 正文、MCP schema、历史片段和详细记忆按需加入；会话中新记忆只落盘，不修改当前快照。

### 2. 从便宜到贵的处理顺序

1. **工具结果截断**：视图中保留头尾并标明省略长度，原始事件保存完整结果。
2. **清理旧工具结果**：达到软阈值后以占位符替换旧内容，不删除消息，不破坏 tool call 配对。
3. **压缩前记忆机会**：需要时先让模型只使用记忆工具，保存真正长期有用的信息；该过程产生 usage 和审计，不自动创建 Skills。
4. **摘要旧回合**：达到硬阈值后只压缩完整回合，保留最近回合、当前计划和证据引用，不出现孤立 tool 消息。
5. **单长回合**：没有安全边界时继续清理工具结果、使用 FTS 检索或只读子任务，不强行切断调用链。

默认软/硬阈值为模型窗口的 70% / 85%，并预留输出空间；实际值进入模型配置。只在接近阈值时改变旧视图，降低前缀缓存失效。

### 3. usage 与摘要约束

- 优先使用 API 的实际 `prompt_tokens`；缺失时使用模型 tokenizer 或保守字符估算并标记 `estimated=true`，不得把成本记为零。
- 摘要保留目标、已完成步骤、关键路径/参数、当前计划、未解决问题和证据引用。
- 历史检索只返回短片段及 session/event 定位，相关原文需要时再读取；摘要是派生物，可从原始事件重建，避免逐轮信息衰减。

## 后果与验证

ContextView 统一恢复、压缩、记忆和检索。测试覆盖头尾截断、配对不变量、冻结快照、压缩前记忆、FTS 片段、单长回合、usage 缺失、摘要来源、视图确定性和原始事件不变；评测同时记录学习效果、token 和延迟。
