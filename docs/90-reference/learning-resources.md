# 外部学习资料

## 课程与教程

- [Hello Agents（Datawhale）](https://datawhalechina.github.io/hello-agents/) — 中文 Agent 教程，`hello_agents/` 的上游
- [agents-from-scratch（LangChain）](https://github.com/langchain-ai/agents-from-scratch) — L3 课程主线
- [LangChain Academy：Intro to LangGraph / Ambient Agents](https://academy.langchain.com/courses/intro-to-langgraph)
- [Handy Multi Agent（Datawhale）](https://datawhalechina.github.io/handy-multi-agent/) — 一起学多 AI 智能体系统
- [HuggingFace MCP Course](https://huggingface.co/learn/mcp-course/unit0/introduction)

## 模式与架构

- [all-agentic-architectures](https://github.com/FareedKhan-dev/all-agentic-architectures) — L4 模式清单来源
- [Agentic Design Patterns（Andrew Ng）](https://docs.google.com/document/d/1rsaK53T3Lg5KoGwvf8ukOUvbELRtH-V0LnOIFDxBryE/)

## 开发框架对比

- [LangChain / LangGraph](https://github.com/langchain-ai) — 灵活串联组件，构建复杂操作序列与图编排
- [CrewAI](https://github.com/crewAIInc/crewAI) — 面向多智能体、角色与任务协作的结构化框架
- [Google ADK](https://github.com/google/adk-python) — 构建评估部署一体化，与谷歌 AI 基础设施集成
- [smolagents（HuggingFace）](https://github.com/huggingface/smolagents) — 最小内核设计参考
